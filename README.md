# Git və GitHub Praktiki Tapşırıq
**Ad və Soyad:** Şamilzadə Şamil

## Layihənin qısa izahı
Bu layihə Git komandalarını praktikada öyrənmək, branch-lərlə (qollarla) işləmək və GitHub-da repository yaratmaq məqsədilə hazırlanmışdır.

## Layihədə olan fayllar
- index.html
- app.py
- README.md

## İstifadə etdiyim əsas Git komandaları
1. git init
2. git status
3. git add .
4. git commit -m "mesaj"
5. git branch -M main
6. git switch -c branch_adi
7. git merge branch_adi
8. git push
